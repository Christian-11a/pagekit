# PageKit sample previews

These three images render PageKit's own synthetic application letter, CV, and certificate. They contain sample data, not real applicant documents. They were rendered with Poppler from locally verified sample exports. The CV export was rotated during the workflow test; the hero displays it upright with a CSS transform.

The images total approximately 67 kB and load locally. They do not import the PDF engine. The three-page composition is labeled as an example export; the interactive sample button loads the full five-page sample workspace.
